# Электронная торговая сеть (Django REST API)
## Описание
API для управления иерархической сетью поставщиков электроники с тремя уровнями:
- Завод (уровень 0)
- Розничная сеть (уровень 1)
- Индивидуальный предприниматель (уровень 2)

## Технологии
- Python 3.10+
- Django 4.2
- Django REST Framework
- PostgreSQL

## Установка
1. Клонируйте репозиторий:
```
git@github.com:RadmilaGMTD/electronics.git
```
2. Установите зависимости:
```
poetry install
```

3. Настройки:

* Создать файл .env на основе .env.example

* Указать настройки БД и секретный ключ

4. Примените миграции:

```python manage.py migrate```

5. Создать суперпользователя:

```python manage.py createadmin```

## API Endpoints
### Поставщики
* GET '' - Список поставщиков (фильтрация по country)

* POST /create/ - Создать поставщика

* GET /suppliers/{pk}/ - Детали поставщика

* PUT/PATCH /suppliers/{pk}/ - Обновить (запрещено обновлять debt)

* DELETE /suppliers/{pk}/ - Удалить поставщика

### Пользователи
* POST /users/create/ - Регистрация

* GET /users/list/ - Список пользователей (только для авторизованных)

### Админ-панель
Доступна по адресу /admin/ после создания суперпользователя. Возможности:

* Просмотр всех объектов

* Фильтрация поставщиков по городу

* Action для очистки задолженности

* Ссылки на поставщиков в детальной view

## Бизнес-правила
### Иерархия:

* Завод (уровень 0) → Розница (уровень 1) → ИП (уровень 2)

* Максимальная глубина цепочки: 3 уровня

### Ограничения:

* Завод не может иметь поставщиков или задолженность

* ИП не может закупать у другого ИП

* Розница не может закупать у ИП
